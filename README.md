# CEL RUSH (셀 러시)

만화책이 그대로 움직이는 화면으로 달리는 웹 아케이드 레이서. 기획서는 볼트의 `2-Areas/Ideas/Cel Rush/셀러시-기획서.md`.
자동차판과 보트판이 한 코드베이스를 공유하고, 물리 모듈만 다름. 보트판은 inkquake 코드를 쓰지 않고 처음부터 새로 짠 것.

## 실행

가장 쉬운 방법: 폴더의 `start.bat`을 더블클릭. 처음 한 번은 패키지를 설치하고, 게임 서버를 띄운 뒤 브라우저를 자동으로 엶. 창을 닫으면 서버도 꺼짐.

`index.html`을 직접 여는 방식은 안 됨. 소스가 TypeScript라 Vite가 변환해 줘야 하고, 빌드 결과물도 브라우저가 `file://`에서 모듈 스크립트를 막기 때문에 로컬 서버가 필요함.

터미널에서 직접 할 때:

```
npm install
npm run dev        # http://localhost:5190
npm test           # 코스 검증 + 헤드리스 물리 테스트
npm run build      # dist/ 정적 빌드 (네트워크 요청 0건)
```

## 조작

| 키 | 동작 |
|---|---|
| A D / ← → | 조향 |
| W / ↑ | 가속 |
| S / ↓ | 감속, 정지 상태에서 후진. 공중에서는 기수 들기 |
| Space / Shift | 드리프트. 누른 채 코너를 돌면 3단계로 차지, 떼면 부스트 |
| R | 리스폰 |
| C | 카메라 전환 (추격 / 근접 / 후드) |
| Esc | 일시정지 |
| F2 | 셀셰이딩 튜닝 패널 (아웃라인 두께, 하프톤, 명암 경계, 블룸) |

메뉴는 WASD 또는 방향키로 이동하고 Enter나 Space로 고름.
게임패드: 왼쪽 스틱 조향, RT 가속, LT 감속, A/RB 드리프트, Start 일시정지.
카운트다운 마지막 0.45초 안에 가속을 누르면 로켓 스타트.

## 코스와 모드

- 자동차: 하버 시티(낮, 운하 다리), 알파인 패스(석양, 고갯길), 네온 하이웨이(야간, 고가도로)
- 보트: 에메랄드 베이(맑은 만, 점프대), 레드 캐니언(협곡 급류, 물살), 스톰 해협(폭풍우, 큰 너울)
- 모드: 레이스(AI 3대, 3바퀴), 타임어택(최고 랩 고스트), 서바이벌(구간 통과마다 시간 연장)

## 구조

```
src/core       고정 120Hz 루프, 입력, 시드 난수와 노이즈
src/tuning     palette.ts (색 리터럴은 이 파일에만), params.ts (물리/렌더 튜닝값)
src/physics    강체 (6자유도, 박스 관성), 정적/구 충돌 임펄스
src/track      스플라인 코스 정의, 균일 샘플링, 투영
src/world      차 노면 높이 함수, 거스너 파도 (CPU와 GLSL이 같은 배열 사용)
src/vehicles   car.ts, boat.ts, boatHull.ts, drift.ts, models.ts
src/render     툰 셰이더, 물, 하늘, 후처리 파이프라인
src/scene      코스별 월드 생성 (도로, 지형, 건물, 섬, 협곡, 부표)
src/fx         만화식 파티클, 스키드 마크, 항적 폼 맵
src/game       레이스 규칙, AI, 고스트
src/ui         HUD(캔버스), 메뉴(DOM), 설정
```

## 설계 요점

렌더링 순서는 기획서대로 아웃라인, 하프톤, 블룸, 색보정. 툰 셰이더가 색과 뷰 노멀, 명암 단계, 아웃라인 클래스를 MRT로 한 번에 쓰고, 합성 패스가 깊이와 노멀 불연속으로 선을 그림. 선은 가까운 쪽 픽셀에만 그려서 이중선이 생기지 않음. 하프톤은 화면 좌표에 고정.

자동차 물리는 서스펜션 레이캐스트 4개(스프링, 댐퍼, 안티롤바)와 슬립각 기반 타이어 모델(마찰 타원)로 움직임. 드리프트 중에는 뒷바퀴 접지력이 떨어지고, 아케이드 보조로 속도 벡터를 코너 쪽으로 돌리면서 요 제어기가 드리프트 각도를 유지함.

보트 물리는 선체 샘플점 40개가 각자 물기둥 부력, 선체 법선 방향의 동압(활주 양력과 슬래밍), 선체 좌표계 기준의 비등방 항력(용골)을 받음. 프로펠러가 물 밖으로 나오면 추력이 사라지고 엔진음이 올라감. 활주 구간의 트림(험프 후 약 4도)과 선회 시 안쪽 기울기는 PD 제어로 보조함. 선체 형상 함수 하나를 물리와 모델이 같이 씀.

## 검증 도구

- `npm test`: 코스 자체 교차와 최소 회전반경, 차와 보트의 정지 자세, 0-100 가속, 최고 속도, 선회 반경, 드리프트 속도 유지율, 폭풍 파도 안정성. 수치는 `tests/out/physics.log`에 남음
- URL 파라미터: `?course=harbor&mode=race&auto=1` 메뉴를 건너뛰고 바로 시작, `auto=1`이면 플레이어 차량도 AI가 운전
- 콘솔: `__celrush.advance(10)` 시뮬레이션을 동기적으로 10초 진행 후 한 프레임 그림. `__celrush.freeze = true` 시뮬레이션 정지(카메라는 동작)
